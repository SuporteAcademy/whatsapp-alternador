# Coimbra Academy

Sistema de contato via WhatsApp para a Coimbra Academy.

## Funcionalidades

- Botão de contato direto via WhatsApp
- Alternância automática entre números de consultores
- Interface moderna e responsiva
- Design em tons de azul

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome (ícones)

## Como Usar

1. Clone este repositório
2. Abra o arquivo `index.html` em seu navegador
3. Clique no botão "Falar com Consultor" para iniciar uma conversa no WhatsApp
